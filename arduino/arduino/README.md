# Lamp code

The sketch is `arduino/lumi_lamp/lumi_lamp.ino` (Arduino Uno).

Parts: Arduino Uno R3, HC-SR04 ultrasonic sensor, 0.96" SSD1306 OLED (I2C),
5V active buzzer, push-button. Wiring and behaviour are in the main README.

Libraries: Adafruit SSD1306, Adafruit GFX Library.

It speaks the USB protocol described in the main README (115200 baud).
