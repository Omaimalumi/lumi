Lumi — Technical Spec

How the three pieces of Lumi work together, and how the demo session flows through them.

How This Works, In Plain Language

1. The lamp

Arduino + distance sensor + small screen + buzzer. Decides if you're there, runs the countdown, draws the eyes and messages.

2. The web page

Runs in Chrome or Edge. Talks to the lamp over the USB cable using Web Serial. Shows the timer, settings, and the study buddy.

3. The study server

A small program on your computer. Keeps your notes and talks to Gemini. Your API key lives only here, in .env.

The lamp is the boss of the timer. The page just copies what the lamp says. The AI lives on the server. That's why an AI problem can never stop your study session.

Your Useful Unknown: How the Page Talks to the Lamp

Every second, the lamp sends one line like this. Click any value to see what it means:

Click a value above.

The page sends short commands back. The first letter is the kind of command:

F40               → focus length is 40 minutes
MREVIEW: MITOSIS  → show this message for about 4 seconds (21 characters max)
T                 → play the tune

Try it yourself during the build (about 5 minutes, no code changes): with the page disconnected, open the Arduino IDE's Serial Monitor at 115200 baud. Watch the mode change from 0 to 3 to 4 as you sit down. Then type MHELLO and watch it appear on Lumi's screen.

USB Messages (Page ↔ Lamp)

Lamp → page: S,mode,focusDone,focusMin,breakMin,modeSec,dist,pomos,today,here,overlay,pending every second, plus E,DONE when a session finishes.

Page → lamp: A acknowledge saved seconds · K task · F focus length · B break length · M message (21 characters max) · T tune.

PRD: Connecting the Lamp · Weak Spots on the Lamp

Web Page: Connection and Timer web/index.html

Connects to the lamp, reads its status lines, shows the timer card (character, progress ring, countdown, focusing/paused/break label), and sends the focus time. Shows "Lost the lamp connection. Plug it back in…" if the cable is pulled.

PRD: Connecting the Lamp · Noticing You · States and Boundaries

Web Page: Focus Mode web/index.html

Hides everything except the timer. The exit button or Esc brings the page back. The timer keeps running, because the lamp drives it.

PRD: Focus Mode

Web Page: Study Buddy Quiz web/index.html

5 questions, one at a time. Asks the server for each question, shows "Question N of 5 · Topic," sends answers for grading, and keeps score per topic. New weak spot → sends MREVIEW: TOPIC to the lamp. Ends with the score, weak spots, and what to review next.

PRD: AI Study Buddy Quiz · Weak Spots on the Lamp

Study Server server/server.js

Serves the page, receives uploads, picks the most relevant chunks of your notes by matching keywords, and calls Gemini. Only listens on your own computer.

EndpointWhat it does
GET /api/statusIs the AI ready? Is it in Practice mode?
POST /api/uploadReceives note files, pulls out the text, saves chunks
POST /api/quiz/questionReturns {topic, question, answer} from your notes
POST /api/quiz/gradeReturns {correct, feedback}

Where It Runs

Locally, on your computer. No deployment. You need Node.js 18+, Chrome or Edge, the lamp on USB, and your key in .env.

npm install     (first time only)
npm start

Open http://localhost:8787 and click Connect lamp. Close the Arduino Serial Monitor first, since only one program can use the USB connection at a time.

For the video: about 1-minute custom focus time · notes uploaded first · Focus mode for the timer moments · scroll to the Study buddy for the quiz.
